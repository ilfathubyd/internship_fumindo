# 💻 Frontend - Fumindo Asset Management System

Single Page Application (SPA) responsif untuk Sistem Manajemen Aset Fumindo yang dibangun menggunakan **Vue.js 3** (`<script setup>`, Composition API), **Vite**, dan **Axios**.

## 📌 Fitur Frontend
- Dashboard metrik statistik aset real-time.
- Pencarian dan filter kategori secara instan.
- Modal tambah, edit, dan konfirmasi hapus data.
- Toast feedback visual responsif.
- Vite dev server dengan proxy API ke backend (`/api` -> `http://localhost:3000`).

## 🛠️ Setup & Development

```bash
# 1. Install dependencies
npm install

# 2. Jalankan development server
npm run dev

# 3. Build untuk production
npm run build
```
